Project Title: Soroban GradeTracker
Description
The Soroban GradeTracker is a decentralized academic record management system built on the Stellar network. It leverages Soroban smart contracts to allow students or educators to securely store, update, and manage academic grades. By utilizing blockchain storage, the project ensures that data is handled in a transparent and persistent environment.

Vision
To provide a lightweight, transparent, and immutable foundation for academic record-keeping. The vision is to empower students with control over their own academic data while demonstrating the practical utility of smart contracts in educational administrative systems.

List of Project Features
Persistent Storage: Grades are stored directly on the Stellar blockchain using instance storage.

Grade Management (CRUD): * Create/Update: Add new subjects and grades or update existing ones.

Read: Retrieve specific grades using subject identifiers.

Delete: Remove specific subject records from the contract state.

Gas-Efficient Logic: Optimized Rust code to minimize resource consumption during contract execution.

Default Handling: Built-in logic to return a default value (0) if a subject is not found, preventing contract panics.
